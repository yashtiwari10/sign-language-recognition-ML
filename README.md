🖐️ Sign Language Recognition using Machine Learning

A real-time hand gesture recognition system built using Python, OpenCV, and TensorFlow Lite.
The model can detect three signs from a live webcam feed:

👍 Thumbs Up

👌 OK Sign

✌️ Victory Sign

This project demonstrates how machine learning and computer vision can help bridge communication barriers for individuals with speech or hearing impairments.

📌 Overview

This project captures hand gesture images using a webcam, trains a machine learning classifier, converts it into a TensorFlow Lite model, and performs real-time inference.
It is lightweight, fast, and completely runs on the CPU.

🎯 Features

📷 Live webcam gesture detection

🤖 TensorFlow Lite–based lightweight model

✨ Three supported gestures (thumbs up, OK, victory)

⚡ Fast inference

💾 Auto image collection for dataset creation

🧠 Modular training + inference code

🛠️ Technology Stack

Python 3.x

OpenCV

TensorFlow Lite (TFLite)

NumPy

Scikit-learn
